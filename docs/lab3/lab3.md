
# Отчёт о выполнении лабораторной работы №3 "Проектирование ИС"

## 1. Постановка задачи
Целью лабораторной работы является освоение навыков проектирования информационной системы на примере интернет-магазина компьютерных игр. Необходимо разработать набор UML-диаграмм, спецификации системы с использованием методов Event Storming и Event Modeling, а также описать архитектуру системы с помощью C4 Model.

## 2. Стратегия дизайна
При проектировании системы использовался объектно-ориентированный подход и язык моделирования UML. Для описания бизнес-процессов применялись методы Event Storming и Event Modeling. Архитектура системы разрабатывалась с использованием подхода C4 Model, предполагающего последовательную декомпозицию системы на контексты, контейнеры и компоненты.

## 3. Диаграммы UML
В ходе выполнения работы были разработаны следующие UML-диаграммы:
- Диаграммы вариантов использования (use case) и сценарии
- Диаграммы деятельности
- Диаграммы классов
- Диаграммы последовательности
- Диаграммы компонентов
- Диаграмма пакетов
- Диаграмма развертывания
- ER-диаграмма базы данных

Все диаграммы были выполнены с использованием языка PlantUML и размещены в Wiki проекта.

## 4. Event Storming
Для лучшего понимания предметной области и основных бизнес-процессов системы было проведено моделирование в формате Event Storming. В результате были определены основные события, команды и агрегаты системы. Итоговая диаграмма Event Storming представлена в Wiki проекта.

## 5. Event Modeling
Дополнительно к Event Storming было проведено более детальное моделирование поведения системы с помощью метода Event Modeling. Были выявлены ключевые процессы обработки событий и взаимосвязи между ними. Результирующая диаграмма Event Modeling также доступна в Wiki проекта.

## 6. Архитектура C4 Model
На основе полученных знаний о структуре и поведении системы была разработана её архитектура в нотации C4 Model. Были последовательно созданы следующие диаграммы:
1. Контекстная диаграмма (Context)
2. Контейнерная диаграмма (Container)
3. Компонентная диаграмма (Component) 

Архитектурные диаграммы выполнялись на языке PlantUML с использованием библиотеки C4-PlantUML.

## 7. Заключение
В результате выполнения лабораторной работы были получены практические навыки проектирования информационной системы. Изучены нотации и инструменты моделирования UML, Event Storming, Event Modeling и C4. 

Полученный набор диаграмм и спецификаций позволяет составить целостное представление об архитектуре и бизнес-процессах разрабатываемого интернет-магазина компьютерных игр. В дальнейшем эти артефакты могут быть использованы для детализации требований, планирования разработки и организации взаимодействия в команде проекта.
