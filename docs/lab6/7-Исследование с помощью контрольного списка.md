## Итог исследования:

### Веб-приложение:
- Требуется улучшение кнопок.
- Добавить доступность для экранных считывателей.
- Детализировать ошибки при заполнении полей.

### Мобильное приложение:
- Рекомендуется переработать размер кнопок.
- Улучшить юзабилити в разделе "Библиотека".
- Минимизировать количество кликов для ключевых операций.
