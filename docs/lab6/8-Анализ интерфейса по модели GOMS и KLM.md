# Анализ интерфейса по модели GOMS и KLM

## Анализ по модели GOMS (для веб-приложения)

### 1. Форма регистрации
- **Метод ввода: только мышь**
  - Ввод имени: щелчок по полю → ввод текста (7 сек).
  - Ввод email: щелчок → ввод текста (7 сек).
  - Ввод пароля: щелчок → ввод текста (7 сек).
  - Подтверждение: щелчок на кнопку (2 сек).
  - **Итог:** ~23 сек.
- **Метод ввода: клавиатура + мышь**
  - Щелчок по первому полю → Tab для перехода → ввод данных (7 сек).
  - Повторение для каждого поля → подтверждение кнопкой (2 сек).
  - **Итог:** ~20 сек.

### 2. Форма поиска
- **Метод ввода: только мышь**
  - Щелчок по полю → ввод текста → нажатие кнопки (5 сек).
  - **Итог:** ~5 сек.
- **Метод ввода: клавиатура + мышь**
  - Tab для перехода к полю → ввод текста → Enter для поиска (4 сек).
  - **Итог:** ~4 сек.

### 3. Форма оформления заказа
- **Метод ввода: только мышь**
  - Выбор товара: 2 щелчка → переход к оформлению (5 сек).
  - Ввод данных доставки: щелчки → ввод (10 сек).
  - Подтверждение заказа: щелчок (2 сек).
  - **Итог:** ~17 сек.
- **Метод ввода: клавиатура + мышь**
  - Выбор товара мышью → Tab для перехода к следующему этапу → ввод (9 сек).
  - **Итог:** ~14 сек.

---

## Анализ по модели KLM (для мобильного приложения)

### 1. Вход в аккаунт
- **Оценка времени:**
  - Тап по полю для ввода email → ввод текста (5 сек).
  - Тап по полю пароля → ввод текста (5 сек).
  - Нажатие кнопки "Войти" (2 сек).
  - **Итог:** 12 сек.

### 2. Поиск игры
- **Оценка времени:**
  - Тап по строке поиска → ввод текста (5 сек).
  - Тап по кнопке "Поиск" (2 сек).
  - **Итог:** 7 сек.

### 3. Покупка игры
- **Оценка времени:**
  - Тап на игру → тап "Купить" → подтверждение оплаты (6 сек).
  - **Итог:** 6 сек.

---

## Выводы и рекомендации

### GOMS:
- Навигация с использованием клавиатуры и мыши показывает меньшую продолжительность операций (на ~15% быстрее).

### KLM:
- Мобильная версия интуитивна, но можно сократить время за счёт автофокусировки на полях ввода.

### Общие рекомендации:
1. Добавить подсказки для полей ввода.
2. Увеличить зоны нажатия кнопок для мобильного приложения.
3. Упростить этапы оформления заказа для снижения количества кликов.
