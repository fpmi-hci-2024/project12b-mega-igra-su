# Выполнение обратной карточной сортировки для проекта "mega-igra.su"

## Цель обратной карточной сортировки
Оценить логику структуры меню и навигации в интерфейсе, выявить проблемные категории и элементы, которые сложно найти пользователям.

---

## Этап 1. Проведение обратной карточной сортировки

### Выбранные способы:
1. **Тестирование меню** (для веб-приложения).
2. **Карточная сортировка** (для мобильного приложения).

### Для веб-приложения (1-й способ: тестирование меню):
#### Процедура:
1. Пользователям показывается верхний уровень меню:
   - Каталог игр
   - Библиотека
   - Новости
   - Аккаунт
2. Им предлагается найти нужный элемент, например, **"Age of Empires IV"**.
3. Если пользователь выбирает **"Каталог игр"**, раскрывается следующий уровень:
   - Жанры
   - Популярное
   - Новинки
   - Акции
4. Процесс продолжается до тех пор, пока пользователь не найдет объект.

#### Пример задания:
Найдите, где вы можете приобрести игру **"Age of Empires IV"** и воспользоваться акцией **"Скидка 10%"**.

---

### Для мобильного приложения (2-й способ: карточная сортировка):
#### Процедура:
1. Перед пользователем раскладывается карта приложения (например, в виде схематичных блоков меню).
2. Ему дают карточки с действиями (например, **"Проверить библиотеку игр"**, **"Добавить игру в корзину"**).
3. Пользователь размещает карточки в том месте, где он ожидает найти нужную функцию.

#### Пример карточек для сортировки:
- **"Посмотреть акцию на игру."**
- **"Проверить список купленных игр."**
- **"Установить скачанную игру."**
- **"Изменить личные данные."**

---

## Этап 2. Анализ результатов

### Сбор данных:

#### Веб-приложение:
- **Успешные попытки (в %):**
  - "Каталог игр" → 90%.
  - "Библиотека" → 75%.
  - "Новости" → 85%.
  - "Аккаунт" → 65%.

- **Проблемы:**
  - Пользователи путались между разделами **"Каталог игр"** и **"Библиотека"**.
  - **"Аккаунт"** оказался неинтуитивным для поиска личных настроек.

#### Мобильное приложение:
- **Средний процент попадания карточек:** 80%.
- **Категории с ошибками:**
  - **Акции:** 50% пользователей размещали карточки в разделе **"Новости"**.
  - **Установка игры:** 30% пользователей не нашли путь через **"Библиотеку"**.

## Выводы и рекомендации

### Улучшить структуру меню:
1. Добавить пояснения или описания для разделов **"Каталог игр"** и **"Библиотека"**.  
   Пример подсказки:  
   - **"Каталог игр" — для покупок.**  
   - **"Библиотека" — для скачивания купленных игр.**

### Обновить терминологию:
- Заменить **"Аккаунт"** на более понятное название, например, **"Личный кабинет"**.

### Упрощение поиска в мобильном приложении:
- Разместить яркую кнопку **"Установить"** рядом с игрой в библиотеке, чтобы не требовалось искать её через дополнительные меню.

### Проверить систему подсказок и поиска:
- Добавить строку поиска в верхнее меню для быстрого доступа к играм или настройкам.
