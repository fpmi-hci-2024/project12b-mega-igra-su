# Название, цель и задачи работы

## Название:
**Анализ и тестирование пользовательского интерфейса приложения для электронной торговли видео-играми.**

## Цель:
Изучение методов оценки ранних концепций и совершенствование интерфейсов веб- и мобильного приложения "mega-igra.su".

## Задачи:
1. Оценить удобство и функциональность интерфейса.
2. Провести обратную карточную сортировку и тестирование ожиданий.
3. Проверить интерфейс на соответствие контрольным спискам usability.
4. Исследовать интерфейс по методам GOMS, KLM или TLM.
5. Оценить показатели task success и time-on-task.
6. Провести исследование с помощью анкеты SUS.
7. Разработать рекомендации по улучшению интерфейса.
