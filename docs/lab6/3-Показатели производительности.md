# Показатели производительности

Для оценки производительности действий пользователей в процессе тестирования были установлены следующие критерии:

| **Действие**                                | **Целевое время (сек.)** | **Успешность (доля пользователей, %)** |
|---------------------------------------------|--------------------------|----------------------------------------|
| Переход в "Каталог игр"                     | 5                        | 90                                     |
| Поиск игры через фильтры                    | 30                       | 85                                     |
| Добавление игры в корзину                   | 10                       | 95                                     |
| Завершение покупки                          | 45                       | 80                                     |
| Установка игры из библиотеки               | 60                       | 85                                     |
| Обращение в службу поддержки через форму    | 120                      | 75                                     |

## Анализ:
1. **Наибольшее количество времени** тратится на обращение в службу поддержки, что указывает на необходимость оптимизации раздела "Помощь".
2. **Высокая успешность выполнения действий**, связанных с покупкой, говорит о хорошем UX в основных сценариях.
3. **Фильтры поиска** требуют небольших доработок, чтобы упростить их использование.
