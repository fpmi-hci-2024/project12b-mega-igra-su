# Тестовые задания, сформированные в соответствии с пользовательскими сценариями

## Сценарий: Покупка игры через каталог
**Описание:** Пользователь хочет найти и купить игру через каталог игр.

### Тестовое задание:
1. Перейдите в раздел "Каталог игр".
2. Найдите игру **"Cyber Adventure 2"**.
3. Добавьте игру в корзину.
4. Перейдите в корзину, убедитесь, что выбранный товар отображается корректно.
5. Оформите заказ, выбрав способ оплаты **"Банковская карта"**.
6. Завершите процесс покупки.

---

## Сценарий: Установка купленной игры
**Описание:** Пользователь хочет установить игру, уже купленную ранее.

### Тестовое задание:
1. Перейдите в раздел **"Моя библиотека"**.
2. Найдите игру **"Battle Quest"**.
3. Нажмите **"Установить"**.
4. Следуйте шагам установки.
5. После завершения установки запустите игру через библиотеку.

---

## Сценарий: Поиск игр по фильтрам
**Описание:** Пользователь ищет игры с определёнными характеристиками.

### Тестовое задание:
1. Перейдите в раздел **"Каталог игр"**.
2. Настройте фильтры:
   - Жанр – **"Экшен"**,
   - Рейтинг – **"4+ звезды"**,
   - Цена – **"до 2000 рублей"**.
3. Найдите игру, которая соответствует критериям, и добавьте её в корзину.
4. Вернитесь в каталог и сбросьте фильтры.

---

## Сценарий: Оценка технической поддержки
**Описание:** Пользователь обращается за помощью в службу поддержки.

### Тестовое задание:
1. Перейдите в раздел **"Помощь"**.
2. Найдите ответ на вопрос **"Как восстановить забытый пароль?"**.
3. Если ответа недостаточно, отправьте запрос через форму обратной связи.
4. Проверьте, через сколько времени вы получите ответ.
